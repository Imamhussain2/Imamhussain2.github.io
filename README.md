# GitHub Pages Portfolio — Imamhussain Naikwade

## 1. Create the repository

Create a **public** GitHub repository named:

`YOUR-GITHUB-USERNAME.github.io`

GitHub Pages uses this special repository name for a personal/user site.

## 2. Upload these files

Upload:
- `index.html`
- `style.css`
- `script.js`

Keep all three files in the repository root.

## 3. Enable GitHub Pages

Open:

**Repository → Settings → Pages**

Under **Build and deployment**:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
- Save

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io`

## 4. Personalize before publishing

Search the files for:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`
- `View project →`

Replace those with your actual links.

You can also add your resume as `resume.pdf` and change the "View my work" or contact section to link to it.

## Optional

GitHub Pages also supports custom domains. If you later buy a domain, configure it through Repository → Settings → Pages.
